## 4. Intersection types (`&`)

An intersection combines the requirements of multiple types.

`BookDetails` requires both properties:

### Union vs intersection

Union: `A | B`

A value may match either alternative.

A value needs to satisfy at least one alternative. Access to a property unique to one variant generally requires narrowing first.

Intersection: `A & B`

A value must satisfy both.

A useful memory trick:

- `|` means alternatives.
- `&` means combined requirements.

Be careful when intersecting types that define the same property incompatibly. For example, `{ value: string } & { value: number }` produces an impossible `value` type (`never`).
